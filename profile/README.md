# Markloop

**Your AI writes the doc. People comment. Your AI updates it.**

Markloop turns the HTML documents your AI writes (specs, proposals, plans, reports) into one link your team or clients can comment on. Reviewers click an element or select text and leave a comment, with no account needed on a public link. Your AI pulls the comments in, applies them, and publishes the next version at the same link.

**Publish → Comment → Update ↻** as often as the work needs.

### Works with your AI tool

Claude (claude.ai, Claude Code, Cowork), ChatGPT and Codex, Cursor, VS Code, Grok and other MCP clients connect to one remote MCP server:

```
https://app.markloop.io/api/mcp
```

Sign-in is OAuth in the browser. There is no API key. Setup for each tool: [markloop.io/docs/connect](https://markloop.io/docs/connect).
